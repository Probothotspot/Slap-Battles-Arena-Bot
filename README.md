# Slap Battles Arena Bot

Модульный проект автономного боевого бота для Slap Battles.

## Текущее состояние

Версия **0.1.2 — каркас проекта**. Реализованы загрузка модулей, окно состояния,
перетаскивание и завершение сессии. Повторный запуск завершает предыдущую сессию.
Наблюдение, принятие решений, движение, бой, восстановление и память — явно
обозначенные заготовки. Автоматическая игра пока не реализована.

## Запуск

Для клиентской среды, предоставляющей `loadstring` и `game:HttpGet`:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Probothotspot/Slap-Battles-Arena-Bot/main/loader.lua"))()
```

В обычном Roblox LocalScript такой способ исполнения недоступен. В рабочем
сервере Roblox интерфейс и поведение каркаса ещё не проверены.

### Полоска загрузки

`loader.lua` сразу показывает тонкую фиксированную полоску сверху экрана.
Её единственная надпись меняется между тремя состояниями:

- `loading modules 0/1` — загружается весь комплект модулей.
- `loading modules 1/1` — комплект загружен и приложение инициализировано.
- `error` — ошибка загрузки, проверки, инициализации или доступная ошибка
  приложения после запуска. Подробности в интерфейсе не показываются.

Имена файлов, промежуточные этапы и предупреждения в полоске скрыты. После
появления основного GUI полоска автоматически скрывается. При ошибке запуска
остаётся только `error`; доступная ошибка приложения после запуска снова
показывает полоску с `error`. Боевые модули по-прежнему заготовки: 1/1 означает
загрузку комплекта, а не готовность игрового бота.

Проверки модулей, кеш одной сессии, ограничение ожидания в 20 секунд и очистка
при повторном запуске сохранены. Внутренний отчёт хранит сведения для отладки;
ошибки LogService могут отсутствовать или обрезаться. Ошибка скачивания либо
синтаксиса самого загрузчика возникает до появления полоски.

## Файлы

| Путь | Назначение |
| --- | --- |
| `loader.lua` | Верхняя полоска 0/1, скрытые проверки и кеш модулей |
| `manifest.lua` | Версия, точка входа и список систем |
| `main.lua` | Сборка модулей и жизненный цикл приложения |
| `config.lua` | Общие настройки |
| `Cleanup.lua` | Завершение обработчиков и удаление объектов |
| `Logger.lua` | Сообщения и отладка |
| `Gui.lua` | Интерфейс и управление окном |
| `Perception.lua` | Наблюдение за противниками и ареной |
| `Decision.lua` | Оценка и выбор действий |
| `Navigation.lua` | Передвижение, обход препятствий и края |
| `Combat.lua` | Удары и способности |
| `Recovery.lua` | Смерть, респавн и восстановление состояния |
| `Memory.lua` | История наблюдений за противниками |
| `SlapBattles.lua` | Проверенная интеграция с конкретной игрой |
| `ROADMAP.md` | Очерёдность разработки |

## Исходные наработки

В репозитории [Slap-battles-Teleport](https://github.com/Probothotspot/Slap-battles-Teleport)
уже существуют `Bot SB (недоработанный)`, `Navigation-BOT.lua` и `Slap nearby`.
Они не копируются и не запускаются автоматически. Перед переносом проверяем
их реальные зависимости и совместимость с интерфейсами нового проекта.

Новые версии сначала проверяют текущие файлы репозитория, затем обновляют
нужный модуль. Изменения из ветки `main` подхватываются при следующем запуске;
уже работающая сессия автоматически не обновляется.
