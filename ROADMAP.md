# План разработки

1. Каркас, загрузчик, каталог перчаток и GUI со статистикой — реализованы.
2. Вход через Lobby.Teleport1 с локальным обходом и пересчётом — реализован, нужна проверка в игре.
3. Выбор живой цели, прогноз позиции, удержание дистанции, стандартный путь и ограниченный
   A* по поверхностям/мостам — реализованы и проверены на моделях; нужна проверка на реальной карте.
4. Кнопка просмотра текущего пути и ограниченный пул анимированных следов — реализованы.
5. Подтвердить в игре геометрию, склон досок, действительный проход через портал, Client Streaming,
   нагрузку на телефоне и реакцию на стены/толпу. Отрегулировать параметры по наблюдениям.
6. Поворот к цели, обычная активация, интервал и восстановление дистанции реализованы.
   Подтвердить Tool:Activate, дальность и перезарядку на текущем сервере/перчатке.
   Есть отдельные счётчики попыток и подтверждений; для подтверждений ещё нужно определить
   реальное серверное событие и проверенную корреляцию с ID попытки. Пока источник не подключён,
   GUI показывает «—», не заменяет попадания количеством вызовов Activate.
7. Подключать специальные способности через проверенные адаптеры каждой механики.
8. Добавить уклонение/контратаку и ограниченную память по проверенным наблюдениям.

Локальная модель не заменяет Roblox. Прыжки через неподтверждённые разрывы, точные игровые
перезарядки и победы над сильными игроками не заявляются готовыми.
